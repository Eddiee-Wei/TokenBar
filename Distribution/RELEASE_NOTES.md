## TokenBar 0.2.1

TokenBar brings your Codex quota to the macOS menu bar, so you can check availability without interrupting your work.

### What's New

- Cleaner quota cards with less technical metadata.
- Human-friendly labels for every quota window returned by Codex.
- Clearer highlighting when choosing the quota shown in the menu bar.
- Improved accessibility descriptions for quota selection.
- Bilingual first-launch guidance in the installer and README.

### Install

Download `TokenBar.dmg`, open it, and double-click TokenBar. If macOS blocks the first launch, follow the guidance shown in the installer or repository README.

## 简体中文

TokenBar 将 Codex 额度放进 macOS 菜单栏，让你无需打断工作就能随时查看剩余额度。

### 本次更新

- 精简额度卡片，减少不必要的技术信息。
- 根据 Codex 当前返回结果显示更易理解的额度窗口名称。
- 选择菜单栏额度时提供更明确的高亮反馈。
- 完善额度选择的辅助功能描述。
- 在安装界面和 README 中加入双语首次启动指引。

### 安装

下载并打开 `TokenBar.dmg`，双击 TokenBar 即可。如果 macOS 阻止首次启动，请按照安装界面或仓库 README 中的指引操作。

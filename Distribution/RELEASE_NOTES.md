## TokenBar 0.2.0

TokenBar brings your Codex quota to the macOS menu bar, so you can check availability without interrupting your work.

### What's New

- View 5-hour, weekly, and model-specific quota at a glance.
- Choose which quota appears in the menu bar.
- See reset countdowns and quota status in a compact popover.
- Customize quota colors and use the hold-to-view shortcut.
- Switch between English and Simplified Chinese.

### Install

Download `TokenBar.dmg`, open it, and double-click TokenBar. See the repository README for requirements and installation help.

## 简体中文

TokenBar 将 Codex 额度放进 macOS 菜单栏，让你无需打断工作就能随时查看剩余额度。
